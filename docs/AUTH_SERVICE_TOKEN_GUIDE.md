# Auth Service API & Token Reference Guide

This document provides a comprehensive mapping of every endpoint exposed by **`auth-service`** (`http://45.195.229.15:8111` or `http://localhost:8111`), detailing **which token is required**, along with ready-to-use `curl` commands.

---

## 1. Token Types Overview

| Token Type | Login Endpoint | Request Body | Description & Scope |
| :--- | :--- | :--- | :--- |
| **No Token (Public)** | — | — | Unauthenticated endpoints (Login, Password recovery, Public tenant list). |
| **Platform Super Admin** | `POST /api/v1/auth/login` | `{"usernameOrEmail": "<super-admin-email>", "password": "..."}` | Scope: `SUPER_ADMIN`. Used for hospital onboarding, platform settings, hospital mail, payment gateway configuration. |
| **Hospital Admin** | `POST /api/v1/auth/login` | `{"tenantCode": "GAN-DL", "usernameOrEmail": "...", "password": "..."}` | Scope: `ADMIN` / `HOSPITAL_ADMIN`. Used for staff user management, role creation, and hospital tenant settings. |
| **Any Authenticated User** | `POST /api/v1/auth/login` | Hospital or Super Admin login | Valid token for any logged-in user to check profile, change password, etc. |

## 2. Public Endpoints (No Token Required)

### 2.1 Super Admin Login
* **Description:** Authenticates platform Super Admin. Notice `tenantCode` is **omitted**.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "usernameOrEmail": "<super-admin-email>",
    "password": "<super-admin-password>"
  }'
```

### 2.2 Hospital User Login
* **Description:** Authenticates hospital staff/admin. `tenantCode` is **required**.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "tenantCode": "GAN-DL",
    "usernameOrEmail": "ganesha.admin.dl@gmail.com",
    "password": "Admin@123"
  }'
```

### 2.3 Public Tenant List (Hospital Picker)
* **Description:** Fetches all public clinics/tenants for initial clinic selection dropdowns.
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/public/tenants"
```

### 2.4 Forgot Password
* **Description:** Initiates password reset flow. Super admin omits `tenantCode`; hospital users include `tenantCode`.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/auth/forgot-password" \
  -H "Content-Type: application/json" \
  -d '{
    "tenantCode": "GAN-DL",
    "usernameOrEmail": "ganesha.admin.dl@gmail.com"
  }'
```

### 2.5 Reset Password
* **Description:** Completes password reset using token received via email.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/auth/reset-password" \
  -H "Content-Type: application/json" \
  -d '{
    "token": "RESET_TOKEN_HERE",
    "newPassword": "NewPassword@123",
    "confirmNewPassword": "NewPassword@123"
  }'
```

### 2.6 Token Validation
* **Description:** Service-to-service or client token check.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/auth/validate" \
  -H "Authorization: Bearer <ANY_TOKEN>"
```

## 3. Platform Super Admin Endpoints (Requires Super Admin Token)

> [!IMPORTANT]
> All endpoints below require a token generated by logging in as the super admin.

### 3.1 Onboard New Hospital
* **Description:** Registers a new clinic and provisions an isolated tenant database schema.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/platform/hospitals" \
  -H "Authorization: Bearer <SUPER_ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "clinicName": "Ayur Wellness Center",
    "clinicType": "Clinic",
    "state": "Delhi",
    "city": "New Delhi",
    "pinCode": "110001",
    "addressLine1": "Connaught Place",
    "fullName": "Dr. Ramesh Sharma",
    "mobileNumber": "9876543210",
    "email": "drramesh.ayur@gmail.com",
    "password": "Hospital@2026",
    "confirmPassword": "Hospital@2026"
  }'
```

### 3.2 List All Hospitals
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/platform/hospitals" \
  -H "Authorization: Bearer <SUPER_ADMIN_TOKEN>"
```

### 3.3 Get Hospital by ID
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/platform/hospitals/<HOSPITAL_ID>" \
```

### 3.4 Update Hospital Details

## 4. Hospital Admin Endpoints (Requires Hospital Admin Token)

> [!IMPORTANT]
> All endpoints below require a token from a hospital user with role `ADMIN` or permission `PAGE_SETTINGS` (e.g. `ganesha.admin.dl@gmail.com` with `tenantCode: "GAN-DL"`).

### 4.1 Register New Hospital User
* **Description:** Adds doctors, receptionists, chemists, etc. under the hospital.
```bash
curl -X POST "http://45.195.229.15:8111/api/v1/auth/register-user" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "Dr. Sunita Patel",
    "email": "drsunita.patel@gmail.com",
    "password": "Doctor@2026",
    "role": "DOCTOR",
    "tenantRoleId": "6da0b924-ee78-4cd4-b2e6-4bedd52e3506"
  }'
```

### 4.2 List All Hospital Users
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/auth/users" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>"
```

### 4.3 List Hospital Users (Paged)
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/auth/users/paged?page=0&size=10" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>"
```

### 4.4 Get Single User by ID
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/auth/users/<USER_ID>" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>"
```

### 4.5 Update User Details & Role
```bash
curl -X PUT "http://45.195.229.15:8111/api/v1/auth/users/<USER_ID>" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "Dr. Sunita Patel Updated",
    "role": "DOCTOR",
    "tenantRoleId": "6da0b924-ee78-4cd4-b2e6-4bedd52e3506"
  }'
```

### 4.6 Update User Status (ACTIVE / INACTIVE / LOCKED)
```bash
curl -X PUT "http://45.195.229.15:8111/api/v1/auth/users/<USER_ID>/status" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "INACTIVE"
  }'
```

### 4.7 Soft-Delete User
```bash
curl -X DELETE "http://45.195.229.15:8111/api/v1/auth/users/<USER_ID>" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>"
```

### 4.8 Get Current Hospital Tenant Details
```bash

  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>"
```

### 4.9 List Custom Hospital Roles
```bash

```

### 4.10 Get Single Role Details
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/roles/<ROLE_ID>" \
  -H "Authorization: Bearer <HOSPITAL_ADMIN_TOKEN>"
```

### 4.11 Create Custom Hospital Role

## 5. User Self-Service Endpoints (Any Authenticated Token)

> [!NOTE]
> Works with any valid Bearer token (Super Admin, Hospital Admin, Doctor, Receptionist, etc.).

### 5.1 Get My Profile (`/auth/me`)
```bash
curl -X GET "http://45.195.229.15:8111/api/v1/auth/me" \
  -H "Authorization: Bearer <ANY_AUTHENTICATED_TOKEN>"
```

### 5.2 Update My Profile
```bash
curl -X PUT "http://45.195.229.15:8111/api/v1/auth/me" \
  -H "Authorization: Bearer <ANY_AUTHENTICATED_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "My Updated Name",
    "mobileNumber": "9876543210"
  }'
```

### 5.3 Change My Password
```bash
curl -X PUT "http://45.195.229.15:8111/api/v1/auth/change-password" \
  -H "Authorization: Bearer <ANY_AUTHENTICATED_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "oldPassword": "CurrentPassword@123",
    "newPassword": "NewPassword@123",
    "confirmNewPassword": "NewPassword@123"
  }'
```
